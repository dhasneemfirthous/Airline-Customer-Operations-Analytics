# Airline Customer & Operations Analytics Dashboard

## Project Overview
A four-page Power BI portfolio dashboard exploring simulated airline customer, revenue, and operational data.

> **Data note:** This is a portfolio project using simulated data. It does not represent Emirates or another airline's internal data.

## Dashboard Pages
1. **Executive Overview** — Revenue, flights, passengers, on-time rate, average delay, satisfaction, and monthly revenue.
2. **Customer Insights** — Loyalty tiers, booking channels, ticket fares, travel purpose, and customer satisfaction.
3. **Operations** — Delay patterns, cancellations, flight status, and baggage issues.
4. **Business Insights** — Revenue comparisons by destination, cabin class, travel purpose, loyalty tier, route, and month.

## Repository Contents
- `dashboard-screenshots/` — Screenshots of all four dashboard pages.
- `dataset/` — CSV dataset, if included.
- `powerbi/` — DAX measures, page specifications, and theme file.
- `sql/` — SQL examples for KPI and revenue/operations analysis.
- `Airline_Analytics.pbix` — Add your own saved Power BI report here before publishing if you want visitors to download and interact with it.

## Tools
Power BI, SQL, Python, CSV data.

## How to View
Browse the screenshots in `dashboard-screenshots/`. To interact with the report, download your `.pbix` file and open it in Power BI Desktop.
